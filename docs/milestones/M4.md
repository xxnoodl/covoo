# M4 USB feasibility

Status: implementation support prepared; physical acceptance pending.

## Implementation and architecture

`scripts/network-snapshot.ps1` collects adapter identity, IPv4 bindings and an
optional best route to a literal phone IPv4 address. It changes no network
settings, sends no test traffic and records query failures explicitly. It does
not infer USB from an address prefix or from a cable being connected. No separate
USB audio protocol is introduced: the existing encrypted IP transport is reused.

Run in PowerShell from the repository:

```powershell
./scripts/network-snapshot.ps1 -OutputPath build/network-snapshot.json
./scripts/network-snapshot.ps1 -PhoneAddress PHONE_IPV4 -OutputPath build/usb-route.json
```

Replace PHONE_IPV4 with the actual phone address; do not assume 172.20.10.1.
Use the adapter/interface index to choose the receiver's concrete `--host`
address and scan a fresh QR after changing interfaces. Snapshot files contain
local network addresses; review them before sharing. No pairing secrets or
recorded audio are collected.

## Hardware validation and limitations

Earlier user-reported USB takes succeeded, but the actual per-packet route,
carrier provisioning dependency and wired latency remain unverified. Best-route
queries are routing-table evidence only; they do not prove where an existing
bound socket's packets traveled. Verify socket binding and capture traffic on
the selected interface during the later experiment. Do not install a packet
capture driver automatically.

The missing PC range is [882176,2177664): 1,295,488 frames / 26.989333 seconds.

Sending a datagram does not establish receiver delivery. Phone network_completed

integrity. The phone's complete local reference is preserved; PC has no backfill.

Basic automatic resumption is demonstrated; timely mid-take recovery and
whole-take continuity are not accepted. Investigate reconnect delay, aggregate
completion semantics and gap accounting. Exact physical unplug duration was
not independently measured. No claim of gap-free recovery or M4 completion.
